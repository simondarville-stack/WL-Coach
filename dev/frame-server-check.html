KinEMOS frame server — self check

Dev-only harness for src/kinemos/engine/video/frameServer.ts. Unit tests cover the index arithmetic; this exercises the real WebCodecs path. It encodes a clip whose every frame is a flat grey level encoding its own ordinal, on deliberately uneven frame durations (variable frame rate — the case that breaks currentTime += 1/fps), then reads each frame back through the frame server and checks the pixel says what the index claims. Not part of the production build — Vite only builds index.html, so this page exists under npm run dev only: start the dev server and open /dev/frame-server-check.html.
