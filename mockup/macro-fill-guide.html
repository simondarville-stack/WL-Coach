Per-exercise guide panel. Open from the exercise column header. Set a start value at one week and an end value at another; the trend is interpolated between them and each week is modulated by its week type (High = 100 % of trend, Medium/Low a configurable % below). Preview values appear as blue italics in the column, live, before you commit. Existing entered values (bold) are kept unless you tick overwrite.

Anchors live in the grid — no panel. Click any empty cell in the Snatch column and type a value: it becomes an 📌 anchor. Set two or more anchors anywhere, then press Fill between anchors — every gap is interpolated and modulated by week type using the strip settings above the table. More than two anchors gives you piecewise control (e.g. slow build, then a steep comp push). Click an anchor to remove it.
Rhythm-first, at creation time. The create-macro flow gains one step: paint the week-type rhythm (type a repeating pattern or click weeks to cycle their type), set the modulation once, and seed each tracked exercise with a start → end value. The macro is born with the whole table prefilled — the grid is then for refinement, not data entry.
