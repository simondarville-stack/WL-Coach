Rhythm manage presets…
Model recap: a rhythm preset is either week-type-driven (one multiplier per week type — follows whatever types the weeks already have) or pattern-driven (a repeating multiplier sequence of any length — undulating, step loading, 3:1 blocks — optionally carrying week-type labels it can stamp onto the weeks). Presets are coach-editable and live in settings next to the existing week-type config. The fill guide computes trend(start→end) × rhythm, rounds, and writes plain macro_targets rows. The graph and the grid then edit those same rows directly. Undo restores the pre-fill snapshot — no linked state to maintain.
