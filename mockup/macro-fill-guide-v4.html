Captures: week-type rhythm (sequence) · phases (fractions of length) · tracked exercises · target shapes relative to each exercise's reference · general targets. On a longer/shorter destination: rhythm repeats as a block (default) or stretches; phases scale; values re-interpolate through the fill engine.
Scale test: the graph model is chips + a searchable picker — with 20 tracked exercises you'd graph 2–4 and pick the rest on demand; nothing renders 20 checkboxes. The same graphed-state shows as the ● dot in each table column header, so table and graph stay one mental model. Oversight: the « chevron collapses a column to a 30-px strip that still whispers its max values; the Columns menu hides columns entirely. Proportional fill: pick "All exercises" as target (auto-switches to % of reference) — anchors like 75 % → 98 % fill every exercise from its own reference with one apply; this is the only multi-exercise write besides link drag. Re-modulate re-runs the last apply's anchors + rhythm against the current week types (explicit action, so the table stays plain values). Σreps dot: green = general target within 10 % of the sum of exercise reps that week, amber = drifted; hover for numbers.
