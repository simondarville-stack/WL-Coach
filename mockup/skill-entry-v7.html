EMOS — # Prescription Presets · prototype v7

A preset is anything the coach can prescribe: an optional prescription template written in the normal grammar (80%x5x5, >=85%x3-5x4-6, comma segments — signs and ranges included), plus optional ⏱ / ⏸ features and an optional badge. #5x5 is as valid a preset as #Skill. Try the add field (# …), edit a preset's prescription in the right panel and watch the live preview, then add a row with it. / blocks stay separate, as today.

Applying a preset with a template replaces the row's prescription (features merge; badge per the preset's setting). A template-less preset only adds features/badge. ✕ on a badge removes the tag, keeps prescription and features.

# Preset registry · coach-config

The prescription field speaks the exact planner grammar — invalid input turns the field red and applies nothing. Everything is optional: template only (#5x5), features only (#WOD), or both (#Skill).

Print / athlete view

Badges print only when the preset says so — #5x5 is a coach shortcut, not athlete information, so its badge is off.
