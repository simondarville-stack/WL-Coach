EMOS — # Transformations · prototype v6

Two prefixes, two concepts. / = what a row is (structural blocks: text, video, GPP — as today). # = how a normal exercise is prescribed: a named, coach-configurable bundle of exercise features + a badge. Try the add field: type #, pick a preset, then an exercise. Or type / to see the block list stays separate. Presets are editable in the right panel — changes apply to the next row you add.

Hover a row for its + menu — existing rows can have a preset applied (or removed via ✕ on the badge: removes the badge, keeps the features). A preset is a transformation, not a mode: the row stays a normal exercise; analysis (right column) works exactly as for any other row.

# Preset registry · coach-config

Each preset = badge (name, colour) + the exercise features it applies: load sign, rep-range widening, ⏱ total time, ⏸ rest, and later anything else in the feature registry. Click a preset to edit. This is the coach's system for inventing work types — no new code per type.
